# Desafio1_CN233178_DPSG04L
Desarrollar una aplicación en Next.js con Usestates y Bootstrap para gestionar la venta de boletos en un cine con dos salas, poniendo énfasis en la modularización de componentes y el manejo del estado global con Redux.

Requerimientos:

    Componentización:
        SalaCine: Renderiza la sala seleccionada.
        Asiento: Representa un asiento interactivo.
        ResumenCompra: Muestra el resumen de la compra.
        SelectorSala: Permite cambiar entre salas.
    Estado Global con Redux:
        Manejar disponibilidad de asientos en dos salas.
        Actualizar estado al seleccionar asientos.
        Calcular el total de la compra en tiempo real.
    Interfaz con Bootstrap:
        Mostrar asientos como botones en una cuadrícula.
        Diferenciar asientos disponibles y ocupados .
    Subir a GitHub.
